# Experiment A: Low-dimensional observations and reconstruction

This repository contains a Jupyter notebook and a summary of the first toy experiment.

## Files
- `experiment_a.ipynb`: reproducible notebook with code, results, and mathematical explanations.
- `experiment_a_summary.md`: compact checkpoint to resume the project in a future conversation.
- `requirements.txt`: Python dependencies.

## Setup
```bash
python -m pip install -r requirements.txt
```

Open `experiment_a.ipynb` in VS Code or Jupyter and run cells from top to bottom.

## Current status
The known-rule reconstruction baseline works. The next planned step is Experiment B: learn mappings under unknown linear transformations and test identifiability/generalization.
